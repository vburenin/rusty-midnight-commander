# Apache-2.0 original help text
= Dialogs

Copy, Move, Mkdir, Delete, and similar boxes sit over the panels.

  Tab           move among fields, checkboxes, and buttons
  Space         toggle a focused checkbox
  Enter         activate the focused button
  Esc / F10     cancel

Overwrite asks Yes / No / All / older-or-size variants before replacing
an existing file.

* Copy -> Copy
* Move -> Move
* Mkdir -> Mkdir
* Delete -> Delete
* Find File -> Find File
* Contents -> Contents
