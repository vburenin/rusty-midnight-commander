# Apache-2.0 original help text
= Find File

Command menu Find file searches under a start directory by name and,
optionally, by file content.

Fields: Start at, Filename, Content, Ignore dirs (colon-separated names
skipped when that option is on). Checkboxes cover case, whole words,
regular expressions, recursion, hidden files, and following symlinks.

Tree opens a directory-tree picker for the start path. Start/Again runs
the search. Stop cancels. Chdir jumps to a hit. Panelize loads hits into
the current panel. Quit closes the dialog.

F1 from Find File opens this node. Leaving help restores Find File.

* Contents -> Contents
* Directory tree -> Directory Tree
* External panelize -> External panelize
* Directory panels -> Panels
