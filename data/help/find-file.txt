# Apache-2.0 original help text
= Find File

Command menu Find file searches under a start directory by name and,
optionally, by file content.

Fields: Start at, File name, Content, Enable ignore directories
(colon-separated names skipped when that option is on). The setup form
is two columns: file-name options on the left (Find recursively, Follow
symlinks, Using shell patterns, Case sensitive, All charsets, Skip
hidden) and content options on the right (Whole words, Regular
expression, Case sensitive, All charsets, First hit).

Tree opens a directory-tree picker for the start path. OK starts a new
search. The results dialog lists hits grouped by directory. Found and
Finished (or the current path, or Stopped) sit under the list.
Chdir jumps to a hit. Again asks for new parameters. Suspend pauses a
running or finished find; Continue resumes. Panelize loads hits into the
current panel. View (F3) and Edit (F4) open the selected hit. Quit
closes the dialog.

F1 from Find File opens this node. Leaving help restores Find File.

* Contents -> Contents
* Directory tree -> Directory Tree
* External panelize -> External panelize
* Directory panels -> Panels
