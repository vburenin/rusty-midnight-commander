# Apache-2.0 original help text
= Panels

Two directory panels. The highlighted row is the cursor; the highlighted
panel is active.

  F1 help          F2 user menu       F3 view        F4 edit
  F5 copy          F6 rename/move     F7 mkdir       F8 delete
  F9 menu bar      F10 quit

  Tab switches panel. Enter opens a directory or archive. Insert marks.
  C-r refreshes. C-o toggles the subshell screen.

File menu Help (F1) opens this viewer. Command menu items include
Directory tree, External panelize, Find file, and Screen list.

* Contents -> Contents
* Help viewer keys -> Keys
* Find File -> Find File
* Internal editor -> Editor
* Internal viewer -> Viewer
* Virtual file system -> VFS
* File operations -> Dialogs
