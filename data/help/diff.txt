= Diff Viewer | Diff

Side-by-side comparison of two files (`mcr --diff` or from panels).

  n / N           next / previous hunk
  F4              edit the left file in place
  Shift-F4 / F14  edit the right file
  F5              merge the current hunk
  C-u             swap sides
  C-r             refresh from disk
  F7              search
  F10             quit

Edits return to this viewer and hunks rebuild from the saved files.

* Contents -> Contents
* Internal editor -> Editor
* Directory panels -> Panels
