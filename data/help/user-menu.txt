# Apache-2.0 original help text
= User Menu

User menu (F2) runs commands from `.mc.menu` in the current directory,
else `~/.config/mc/menu`, else a system default.

Each entry has a hotkey and a command line. Macros can expand to the
selected name or path. Esc / F10 closes without running anything.

* Contents -> Contents
* Directory panels -> Panels
* File operations -> Dialogs
