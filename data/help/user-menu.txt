# Apache-2.0 original help text
= User Menu | User Menu

The User menu (F2) runs commands defined by the current directory’s `.mc.menu`
or the user’s `~/.config/mc/menu`. Use it to create quick actions.

Notes:
  - Each menu entry defines a command; some macros expand to filenames or paths.
  - If the local menu file is missing, the user config is used; otherwise system defaults.
