= Viewer

Internal viewer (mcview). F3 from panels opens the highlighted file.

  F2 wrap/unwrap (starts wrapped; hex: Edit/View)
  F3 or q or F10 quit
  F4 hex/text             F5 goto
  F6 save (hex)           F7 or / search (hex: HxSrch)
  n or F17 next match
  Search radios: Normal, Regular expression, Hexadecimal, Wildcard search
  Search options: Case sensitive, Backwards, Whole words, All charsets
  F8 parsed vs raw        F9 format/unformat (nroff)
  | external filter on the viewed bytes

Display options cover line numbers, CR as ^M, wrap, and hex. Shift+arrows
extend a selection. Compressed files may be shown through a filter.

F1 from the viewer opens this node.

* Contents -> Contents
* Internal editor -> Editor
* Virtual file system -> VFS
* Directory panels -> Panels
