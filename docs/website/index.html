A dual-pane file manager in Rust

mcr is the binary of rusty-midnight-commander: an Apache-2.0, clean-room rewrite that aims for cell-accurate visual and interaction parity with GNU Midnight Commander for the features it already ships.

This site is original project documentation. It is not a copy of midnight-commander.org or of the GPL mc/mcedit/mcview/mcdiff manuals. GNU Midnight Commander remains a separate work; we track its public behavior, not its C sources.

What you get in this tree

With no options, mcr opens a full-screen terminal UI on the current directory:

  • Two directory panels, menu bar (F9), mini-status, hint line, shell command line, and F1–F10 labels
  • Internal viewer (F3 / mcr --view), editor (F4 / mcr --edit), and side-by-side diff (mcr --diff)
  • Find File, directory tree, external panelize, user menu, hotlist, skins, and keymaps
  • VFS browse for local files, common archives, and FTP/SFTP/fish (copy-out; not zoo; no archive or remote write)
  • Optional PTY subshell (Ctrl-O), plus built-in F1 hypertext help

The live checklist of what matches GNU mc(1) — and what does not — is docs/PARITY.md. Do not assume an unchecked box is implemented.

Quick start

cargo run --release -p mcr

See Install and build for toolchain pins, man-page install, and CLI flags. See Feature map for a high-level comparison with GNU mc, and Manuals for mcr(1) and friends.
